# RA Layout Manager DE v1.0.1-de.1

Erste deutsche AppImage-Veröffentlichung des RA Layout Managers für Linux.

## Highlights

- 🇩🇪 Benutzeroberfläche weitgehend auf Deutsch
- 🏆 Achievement-Titel werden automatisch ins Deutsche übersetzt
- 📝 Achievement-Beschreibungen werden automatisch ins Deutsche übersetzt
- 💾 Übersetzungen werden lokal zwischengespeichert
- 🔁 Englischer Originaltext als Fallback
- 🎥 Focus-, Alert-, Listen-, Benutzer-, Spiel- und Fortschritts-Overlays
- 📺 Stream-Labels für OBS/Streaming
- 🐧 Linux x86_64 AppImage

## Installation

```bash
chmod +x RA-Layout-Manager-DE-v1.0.1-de.1-x86_64.AppImage
./RA-Layout-Manager-DE-v1.0.1-de.1-x86_64.AppImage
```

## Prüfsumme

Siehe `SHA256SUMS.txt` beim Release.

## Hinweis zur automatischen Übersetzung

Für noch nicht übersetzte Achievement-Texte wird eine Internetverbindung benötigt. Achievement-Titel und -Beschreibungen können zur maschinellen Übersetzung an `translate.googleapis.com` übertragen werden. Bereits übersetzte Texte werden lokal zwischengespeichert.
