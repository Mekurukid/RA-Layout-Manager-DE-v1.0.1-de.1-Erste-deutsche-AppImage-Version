# Security Policy

## Zugangsdaten niemals veröffentlichen

Die Anwendung verwendet einen RetroAchievements Web API Key. Dieser Schlüssel darf nicht in öffentlichen GitHub Issues, Screenshots, Logs oder Konfigurationsdateien veröffentlicht werden.

Wenn du einen Fehler meldest:

- API-Key vollständig entfernen oder schwärzen.
- Keine komplette `settings.json` ungeprüft hochladen.
- Persönliche Pfade oder andere sensible Daten aus Logs entfernen.

Falls ein API-Key versehentlich veröffentlicht wurde, entferne den Inhalt aus dem öffentlichen Beitrag und ersetze bzw. rotiere den Schlüssel über RetroAchievements, sofern diese Möglichkeit angeboten wird.

## Sicherheitsprobleme

Sicherheitsrelevante Probleme sollten möglichst nicht mit funktionierenden Zugangsdaten oder anderen Secrets demonstriert werden. Verwende Testdaten und beschreibe nur die minimal notwendigen Schritte.
