# Datenschutz- und Netzwerkhinweise

## RetroAchievements

Für Live-Funktionen stellt die Anwendung Anfragen an die RetroAchievements API. Dabei werden die für die API notwendigen Kontoinformationen und Abfrageparameter an RetroAchievements übertragen.

## Automatische Übersetzung

Für die automatische deutsche Übersetzung können Achievement-Titel und Achievement-Beschreibungen an folgenden externen Dienst übertragen werden:

```text
translate.googleapis.com
```

Die Anwendung speichert bereits erzeugte Übersetzungen lokal zwischen, um unnötige erneute Übersetzungsanfragen zu vermeiden.

## Lokale Daten

Einstellungen, Übersetzungscache, Fensterpositionen, Spielfortschritt und Stream-Label-Dateien können lokal im Benutzerdatenverzeichnis der Anwendung gespeichert werden.

Der RetroAchievements API-Key ist vertraulich und sollte niemals öffentlich geteilt werden.
