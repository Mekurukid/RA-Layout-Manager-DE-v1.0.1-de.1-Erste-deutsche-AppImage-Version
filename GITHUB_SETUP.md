## Was kommt ins Repository?

Diese Dateien:

```text
README.md
DISCLAIMER.md
CREDITS.md
CHANGELOG.md
SECURITY.md
PRIVACY.md
.github/ISSUE_TEMPLATE/bug_report.yml
screenshots/
```

Die große `.AppImage` kommt **nicht** in das normale Repository. Lade sie beim Erstellen des GitHub Releases unter **Attach binaries by dropping them here or selecting them** als Release-Asset hoch.

## Empfohlene Reihenfolge auf GitHub

1. Neues Repository erstellen: `ra-layout-manager-de-linux`
2. README nicht automatisch von GitHub erzeugen lassen, wenn du dieses Paket hochlädst.
3. Dateien aus diesem Paket in das Repository hochladen.
4. Commit erstellen, z. B. `Initial German Linux release documentation`.
5. Rechts auf **Releases** → **Create a new release**.
6. Tag `v1.0.1-de.1` erstellen.
7. Release-Titel eintragen.
8. Inhalt aus `RELEASE_NOTES_v1.0.1-de.1.md` einfügen.
9. AppImage und `SHA256SUMS.txt` als Dateien anhängen.
10. Release veröffentlichen.
